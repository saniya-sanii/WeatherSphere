# 🌦️ WeatherSphere

WeatherSphere is a responsive weather dashboard that provides real-time weather information for cities around the world using the OpenWeather API.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Current temperature and weather conditions
- 🌡️ Feels-like temperature
- 💧 Humidity information
- 💨 Wind speed
- 📊 Atmospheric pressure
- 👁️ Visibility
- 🌅 Sunrise and sunset timings
- 🕐 Hourly weather forecast
- 📅 5-day weather forecast
- 🌤️ Dynamic weather icons
- ⚠️ Error handling for invalid cities or API errors
- 📱 Responsive and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
